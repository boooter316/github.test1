Local Account Identifier Evidence Scan

Select PDFs or text-based files that you own or are authorized to review. This scan runs locally in this browser only. It counts email-address patterns, labelled Fortnite display-name/username fields, and labelled Epic Account ID fields. It reports file/page/line locations and counts only; it never displays, exports, stores, or uploads matched values.

This is a document index, not an Epic account lookup or ownership verification. It does not search browsers, devices, accounts, websites, or remote systems. Image-only PDFs are not OCR-scanned. Do not select password dumps, browser profiles, cookies, tokens, or authentication-code files.
