EPIC GAMES RECOVERY ASSISTANT — SETUP AND USAGE
================================================

IMPORTANT
---------
This project is an independent recovery organizer and local defensive
diagnostics toolkit. It is not affiliated with Epic Games or other providers.
Use network checks only on devices and networks you own or are authorized to
administer. Do not enter passwords, one-time codes, recovery codes, cookies,
tokens, full payment-card details, wallet seed phrases, or private keys.

A. DOWNLOAD AND EXTRACT
----------------------
1. Open https://github.com/boooter316/github.test1
2. Select Code > Download ZIP.
3. Extract the ZIP to a folder such as C:\Tools\Epic_Games_Recovery_Assistant.
4. Keep the folder structure intact. Do not move individual scripts away from
   the project folder unless you also update the paths in your shortcuts.

B. BUILD THE WINDOWS DESKTOP APPLICATION
----------------------------------------
1. Install a Windows 64-bit MinGW-w64/GCC distribution that provides g++.
2. Add the MinGW-w64 bin directory to the Windows PATH.
3. Open Command Prompt in the Epic_Games_Recovery_Assistant folder.
4. Run: build.bat
5. Confirm that Epic_Games_Recovery_Assistant.exe was created.
6. Run: run.bat

If the build fails:
- Run g++ --version and confirm g++ is found.
- Read the first compiler error, not only the final error count.
- Confirm the source file is named recovery_assistant.c++.
- Run build.bat again after correcting the missing compiler/dependency.
- The GitHub Actions Windows build checks compilation, but cannot test every
  individual Windows PC or local security policy.

C. BROWSER RECOVERY ASSISTANT
-----------------------------
1. Open the web folder and run the Docker commands in web/README.md, or use
   the hosted/static project page if one has been deployed by you.
2. The main page contains Recovery Assistant, Discord Security Scanner,
   Pro Multi-Platform Scanner, Account Links, Account Connections,
   Wireshark & Ports, and Account Status & Details.
3. Use only accurate, non-secret details. Export a JSON packet or print/save
   the recovery request as PDF.
4. The account links are shortcuts only. They do not sign in or connect
   provider accounts. Only the provider can confirm or change account status.

D. LOCAL IP AND NETWORK TOOLS
-----------------------------
Open http://localhost:8080/network-tools.html when running the web container.
The page provides:
- IP evidence notes: IP, observed date/time, city, state/region, ZIP/postal
  code, country, optional street address, evidence source, and notes.
- A command builder for a limited private-network TCP port check.
- Instructions for VPN/proxy configuration status snapshots.
- TXT/PDF export of the IP evidence notes.

The IP/location form performs no geolocation or identity lookup. All location
fields are user-entered and unverified. A street address and IP address are
sensitive; include them only when necessary and keep exports private.

E. WINDOWS VPN / PROXY STATUS CHECK
-----------------------------------
1. Download web/network_tools.ps1 or use the copy in the extracted project.
2. Open PowerShell in the project folder.
3. Run:
   powershell -NoProfile -ExecutionPolicy Bypass -File .\web\network_tools.ps1 -Status
4. The report is saved under %LOCALAPPDATA%\EpicRecoveryAssistant\NetworkStatus.json.
5. The helper reads Windows VPN profile status, network adapter state,
   current-user Windows proxy values, and the WinHTTP proxy summary.
6. It does not connect/disconnect a VPN, change proxy settings, capture
   traffic, inspect credentials, or upload the report.

To install a daily local status snapshot at 9:00 AM:
   powershell -NoProfile -ExecutionPolicy Bypass -File .\web\network_tools.ps1 -InstallDailyStatusTask

To remove the task:
   powershell -NoProfile -ExecutionPolicy Bypass -File .\web\network_tools.ps1 -RemoveDailyStatusTask

The PC must be on and the user must be signed in for the interactive task.
The task writes a local status file only; it does not send notifications.

F. LIMITED PRIVATE-IP TCP PORT CHECK
------------------------------------
Only check a loopback or RFC1918 private IPv4 address on a network you own
or administer. Public targets and address ranges are rejected by the helper.

Example:
   powershell -NoProfile -ExecutionPolicy Bypass -File .\web\network_tools.ps1 -PortCheck -TargetIP 192.168.1.1 -Ports 22,53,80,443,8080

Limits:
- One private IPv4 target per run.
- Up to 32 unique, explicitly selected TCP ports.
- A short connection timeout is used.
- No UDP scan, host discovery, subnet/range scan, exploit test, credential
  attempt, packet capture, or public-IP scan is included.

OPEN means a TCP connection was accepted at the time of the test.
CLOSED_OR_REFUSED means the target rejected the connection or it failed.
NO_RESPONSE_OR_FILTERED means no response arrived before the timeout.
These results are not a vulnerability assessment.

G. EXISTING WIRESHARK & PORT FILTERS
------------------------------------
The existing Wireshark & Ports tab builds display filters such as
tcp.port == 443. A display filter only narrows packets already captured.
Use Wireshark only to capture traffic you own or are authorized to inspect.
The browser's PCAP analyzer reports metadata and does not decrypt TLS or
display packet payloads.

H. VPN / PROXY SAFETY
--------------------
Use the official VPN provider application to connect or disconnect a
third-party VPN. The existing Windows proxy helper may configure a current-
user HTTP/HTTPS proxy; inspect its backup/restore behavior before use.
Do not use proxies or VPNs to impersonate another account owner, bypass
provider security, or conceal unauthorized activity. Scanner inputs and
reports stay local; they are not uploaded through a VPN/proxy.

I. UPDATER AND BUILD MONITORING
-------------------------------
The project updater requires GitHub CLI (gh) and authentication:
   gh auth login
Then review and run update_project.ps1. The optional Windows daily updater
task is installed with install_auto_update.ps1 and removed with its -Remove
switch. It downloads a checksum-verified CI artifact and backs up local files.
It does not execute downloaded code.

Repository build monitoring is separate from the Windows updater. GitHub
Actions validates pull requests and main-branch changes. A successful CI
build is not a guarantee of error-free operation on every PC.

J. PRIVACY / TROUBLESHOOTING
----------------------------
- Do not publish IP/location exports, router snapshots, packet captures, or
  account evidence.
- If a port appears open unexpectedly, identify the service on the device
  itself and review firewall/router rules with the network administrator.
- If VPN/proxy status appears incorrect, compare the helper's read-only
  report with the official VPN application and Windows Settings.
- If the app fails, save the exact error text and relevant log excerpt after
  removing passwords, tokens, cookies, and personal data.
- Never treat an IP address, ZIP code, or street address as proof of account
  ownership. Providers must verify account claims using their own records.
F. GLOBAL STOP, PDF EXPORT, FAZE JARVIS, AND STARTER BUILDER
------------------------------------------------------------
- The sticky Task controls bar is available while navigating every main tab.
  Select Stop current task to request cancellation and abort supported fetches.
  Some synchronous browser operations cannot be interrupted mid-operation;
  they finish their current step. Reload the page to reset the stop request.
- On the Recovery Assistant tab, select Download recovery details as PDF.
  The browser print dialog opens; choose Save as PDF. Review the preview and
  keep the resulting document private. This exports the currently displayed
  recovery page; it does not download scripts or project source files.
- On Account Status & Details, select a provider, record non-secret details,
  then select Print / Save selected account details as PDF. Allow the print
  window if your browser blocks pop-ups, then choose Save as PDF.
- Open the Faze Jarvis AI tab (second tab). It uses the DeepSeek
  chat-completions API through the server-side proxy in server.mjs. The
  server uses the deepseek-flash model with thinking enabled and DeepSeek's
  high safety-check setting. The browser never receives the DeepSeek API key.
- Before starting the container, set DEEPSEEK_API_KEY and CHAT_ACCESS_PASSWORD
  as private environment variables on the host. Do not put either value in
  this repository, HTML, JavaScript, a URL, a screenshot, or a chat message.
  The app access password is entered into the chat page; it is not the
  DeepSeek API key. If either server variable is missing, chat remains off.
- Example local Docker run (replace the placeholders locally; never commit
  real secrets):
  docker run --rm -p 8080:8080 -e DEEPSEEK_API_KEY=YOUR_SERVER_KEY -e CHAT_ACCESS_PASSWORD=YOUR_PRIVATE_CHAT_PASSWORD recovery-assistant-web
- The server limits chat requests and message sizes. Keep the service behind
  authenticated access or a private network; do not expose a paid API proxy
  publicly without appropriate user authentication, usage limits, and
  monitoring. API usage may incur charges on your DeepSeek account.
- The assistant supports coding and defensive security. It does not bypass
  DeepSeek safety controls, authentication, platform restrictions, or access
  controls. Never paste passwords, tokens, recovery codes, private keys,
  payment details, or other secrets into the chat.
- The Build a Starter Project panel creates a downloadable HTML, Python,
  PowerShell, or C++ starter source file from your project description. It
  does not compile or execute generated code. Review the source before use.
  Build the complete Windows application separately with build.bat.
- The coding assistant supports legitimate development and defensive
  security work only; it is not an offensive hacking agent.

G. STOP-CONTROL LIMITATIONS
---------------------------
The Stop control requests cancellation, aborts browser fetches created through
its task controller, blocks form submissions after a stop request, and clears
selected file inputs. It cannot forcibly terminate JavaScript that is already
running synchronously, stop an external Windows process, cancel a program
already launched outside the browser, or undo a recovery request already
submitted to a provider. Recovery requests are drafts only and must be sent
manually by the user through official support.


K. FAZE JARVIS — DEEPSEEK API KEY, SETUP, STATUS, AND TROUBLESHOOTING
-----------------------------------------------------------------------
See web/FAZE_JARVIS_SETUP.md for the full illustrated-by-steps setup, Windows 11 Docker commands, API key creation link, status meanings, and troubleshooting.

Quick summary:
1. Create a key only at https://platform.deepseek.com/api_keys.
2. Create a separate app password.
3. Put DEEPSEEK_API_KEY and CHAT_ACCESS_PASSWORD in a private env file outside the repository.
4. Start/recreate the Docker container with --env-file pointing to that file.
5. In Faze Jarvis, enter only the app access password. Never paste the DeepSeek API key into the browser.
6. Check http://localhost:8080/api/health for configuration presence, then send a test chat message.
API usage may incur charges. Do not expose the plain-HTTP service directly to the public internet.


L. TELEGRAM ACCOUNT CONNECTION AND FORTNITE SKIN CHECK
-------------------------------------------------------
The Telegram Connect tab uses Telegram's official Login Widget. To enable it:
1. Create a bot with official @BotFather and set the website domain.
2. Configure TELEGRAM_BOT_USERNAME and TELEGRAM_BOT_TOKEN privately on the
   Docker host. Never put the bot token in browser code or GitHub.
3. Rebuild/recreate the container and check /api/integrations/status.
4. Select Telegram Connect and approve sign-in through Telegram.
The server verifies Telegram's signed response. The app does not collect a
Telegram password, SMS code, or session token. The verified identity is shown
only in the current page session and is not stored by this app.

The Fortnite Skin Check tab is a local Locker inventory organizer. Enter your
Epic display name as an optional label and manually enter cosmetic names from
your own Fortnite Locker. It counts unique names, detects duplicates, filters,
and exports a TXT report. It does not sign in to Epic, test account credentials,
validate passwords/tokens, or automatically fetch private locker contents.
Epic does not provide this app with a public locker-inventory endpoint. Do
not paste passwords, cookies, session tokens, 2FA codes, or recovery codes.
See web/TELEGRAM_FORTNITE_SETUP.md for complete setup and troubleshooting.
