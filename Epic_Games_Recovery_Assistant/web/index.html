Setup & How to Use

This is the browser-based companion form. It is separate from the Windows desktop executable. The page works in a modern browser; running the hosted C++ web server requires a computer or server environment.

1. Get the project

  1. Open the project repository and download the ZIP archive.
  2. Extract the ZIP on a computer.
  3. Open Epic_Games_Recovery_Assistant/web in a terminal.

2. Run it locally with Docker

  1. Install Docker Desktop (Windows/macOS) or Docker Engine (Linux).
  2. In the web folder, build the container with docker build -t recovery-assistant-web .
  3. Start it with docker run --rm -p 8080:8080 recovery-assistant-web.
  4. Open http://localhost:8080 in your browser.

3. Use the form

  1. Enter only accurate, non-secret account and recovery details.
  2. Record purchase references, optional card last four digits, and truthful historical network context only if relevant.
  3. For a restriction, record the platform, notice date, case number, and appeal explanation. The tool helps prepare an appeal; it cannot remove a restriction.
  4. Select Download JSON packet to save your entries, Print / Save as PDF to create a PDF, or Create support-request draft to prepare a message for official support.
  5. Review the export and share it only through the platform's official secure support channel.

You can also test the static form by opening index.html directly in a modern browser. For a public deployment, use a trusted host with HTTPS; do not expose the plain HTTP server directly to the internet.

Important security notice

This assistant is for legitimate account recovery documentation and appeal preparation only. It does not grab accounts, passwords, tokens, cookies, or private IP data; bypass two-step verification; spoof an original IP; rotate or use VPN/proxy services to impersonate an account owner; unlock accounts; or remove platform restrictions.

It can organize information you provide yourself, such as Epic display name and email, Account ID, purchase references, optional card last four digits, and truthful historical VPN/proxy or IP context. Never enter passwords, 2FA codes, backup codes, tokens, cookies, full card numbers, or CVV.

For Epic, PlayStation, Xbox, Nintendo, Steam, GeForce NOW, Roblox, Minecraft, GTA, Disney, Twitch, YouTube, and TikTok, use the form to document the issue and prepare an appeal where the platform offers one. Only the relevant service can review account access or restrictions.

Notice: This is an independent, local-first organizer. It does not access platform databases, verify ownership, guarantee account recovery, or perform account changes. Use each platform's official support and appeal process.

Discord Security Scanner

This page checks text files you deliberately select on your device for patterns that resemble exposed credentials. It runs locally in this browser tab.

Important limitation: It does not sign in to Discord or Epic, test whether a token is active, verify a login, access browser password stores, or retrieve credentials. It never displays, saves, or sends token values. A pattern match is only a warning—not proof that a credential works.

Scan result

No scan has been run.

Checks include JWT-shaped strings, Discord-token-shaped strings, and credential labels such as password, authorization, and access_token. Only counts and filenames are reported; matched values are discarded immediately.

If a possible secret is found

  1. Do not share the file or scan output publicly.
  2. Revoke or rotate the affected credential using the service's official security settings.
  3. Change a reused password and enable two-step verification.
  4. Remove the exposed secret from public commits and logs; rotating it is still necessary because old copies may remain.

For an exposed Discord webhook, delete/regenerate it in Discord. For Epic Games, use Epic's official account security and recovery pages. This scanner cannot validate or recover an Epic account.

Fortnite Security Scanner

Review Fortnite or Epic text logs and configuration files that you choose on this device. The scan runs locally in this browser tab.

Security boundary: This tool does not access Fortnite or Epic accounts, browser storage, game memory, saved passwords, cookies, or session stores. It cannot validate logins or retrieve tokens. It shows a numbered findings list with file names, line numbers, match categories, and redacted previews. Email addresses, account IDs, and display names are shown in full in this local browser result. Passwords, tokens, cookies, and session secrets are always redacted.

Recommended next steps

  1. If a credential-like pattern is found, do not post the file publicly.
  2. Secure your Epic account through Epic's official account-security page, change a potentially exposed password, and enable two-factor authentication.
  3. Sign out of sessions using the official account controls where available, and rotate any exposed API key or webhook through its provider.
  4. Download Fortnite only through official Epic channels and avoid third-party “token checker” tools.

Keep exported files private. The browser form processes entries in your tab and does not submit them to this site.
