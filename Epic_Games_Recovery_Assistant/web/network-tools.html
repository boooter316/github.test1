Local IP & Network Tools

Local-first tools for documenting your own network details and checking devices you own or are explicitly authorized to administer.

Privacy and scope: This page does not send form data to the web server or perform remote IP geolocation. Address, state/region, ZIP code, and IP notes are user-entered and stay in this browser tab unless you download the report. The port-check helper is restricted to loopback and private IPv4 addresses and at most 32 explicitly selected ports. No public-IP or range scanning.

3. VPN and proxy configuration/status check

The Windows helper reads configured VPN profile names/status, network adapter status, current-user Windows proxy settings, and WinHTTP proxy configuration. It does not inspect VPN traffic, decrypt traffic, read credentials, or change connection settings.

  1. Download network_tools.ps1.
  2. Open PowerShell in the folder containing the downloaded script.
  3. Run powershell -NoProfile -ExecutionPolicy Bypass -File .\network_tools.ps1 -Status.
  4. For a daily local status snapshot, run the install command shown below. It creates a Windows scheduled task under your current user; it does not connect or disconnect VPNs or proxies.

Setup checklist

  1. Download the full project ZIP from GitHub and extract it.
  2. Open Windows PowerShell in Epic_Games_Recovery_Assistant.
  3. Run powershell -NoProfile -ExecutionPolicy Bypass -File .\web\network_tools.ps1 -Status to inspect VPN/proxy status.
  4. Run a generated private-IP port-check command only for a device you own or administer.
  5. Use -InstallDailyStatusTask to schedule a daily status snapshot, or -RemoveDailyStatusTask to remove it.
  6. Use build.bat to build the C++ desktop app and run.bat to launch it. The network tools are a separate browser/PowerShell companion.

For the complete instructions, open SETUP_AND_USAGE.txt. No task or Windows setting is changed by opening this page.
