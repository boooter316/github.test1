# Epic Games Recovery Assistant

A Windows Python desktop utility for organizing truthful Epic Games account recovery information and generating a PDF request.

## Requirements
- Windows 10 or Windows 11
- Python 3.10 or newer
- Internet access to visit Epic Games Support

## Install and run
1. Install Python from https://www.python.org/downloads/ and enable "Add Python to PATH".
2. Double-click `setup.bat` to install ReportLab and launch the app.
3. Use `run.bat` to launch it again later.

## Features
- Account recovery form for current contact email, original email, username, name, region, and other account details
- Hacked, stolen, lost, locked, and unauthorized email-change incident options
- PDF recovery-request generator
- Two-step authentication method/access checklist
- Optional VPN/proxy usage context fields
- Official Epic Games Support link

## Important security limitations
- This app is an independent organizer, not an Epic Games product.
- It does not connect to Epic, verify account ownership, reset passwords, or submit requests.
- It never asks for or stores passwords, 2FA codes, backup codes, or authenticator setup keys.
- Use Epic's official sign-in and account recovery process for verification.
- VPN/proxy fields are for truthful context only. The app does not connect to a VPN/proxy, spoof an IP, recreate an old IP address, or bypass verification.
- Only provide accurate information. Do not guess an original IP address.

Official support: https://www.epicgames.com/help/en-US/
