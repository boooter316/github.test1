# Epic Games Recovery Assistant

A Python desktop utility for organizing Epic Games account recovery information and generating a PDF request.

## Requirements
- Windows 10 or Windows 11
- Python 3.10 or newer
- Internet access to visit Epic Games Support

## Install and run
1. Install Python from https://www.python.org/downloads/
2. During setup, enable "Add Python to PATH".
3. Open this folder and double-click setup.bat.
4. Later, use run.bat to launch the app again.

## Features
- Hacked, stolen, lost, and locked account issue types
- Original email, recovery email, username, name, and state
- Optional remembered original public IP
- Approximate account creation date
- Previous display names and linked gaming accounts
- PDF recovery-request generator
- Official Epic Games Support link

## Security and limitations
This application does not connect to Epic account systems, reset passwords, verify ownership, or submit requests automatically. Never enter passwords, 2FA codes, or backup codes. Only provide accurate information you are comfortable sharing with Epic.

Official support: https://www.epicgames.com/help/en-US/
