Private LAN access

LOCAL SUBNET ONLY

The optional Python host serves static pages to devices on the same private network. It has no remote command endpoint, no file-upload route and no script execution feature.

  • Use a trusted home or office Wi-Fi network.
  • Keep the Windows network profile set to Private.
  • Allow inbound TCP 8765 only for the Windows Private firewall profile and LocalSubnet.
  • Stop the host with Ctrl+C when finished.
  • For devices outside your Wi-Fi, do not port-forward this host.

Start_PRIVATE_DASHBOARD.cmd on your Windows PC, note the displayed private IPv4 address, then open http://YOUR-PRIVATE-IP:8765/DISCORD-SERVER-DASHBOARD/ on another device connected to the same Wi-Fi. This can work without internet access.

OFFLINE LAN

At home, no internet needed

Connect your Windows PC and iPhone to the same trusted Wi-Fi. The local dashboard host checks each request against your exact device IP allowlist.

  1. On iPhone, open Settings → Wi-Fi → ⓘ and note IP Address.
  2. On Windows, run ipconfig and note the PC's Wi-Fi IPv4 address.
  3. Add your iPhone's exact IP to approved_devices.json.
  4. Start START_PRIVATE_DASHBOARD.cmd and open the displayed Windows private IP in Safari.

AWAY FROM HOME

Encrypted private VPN

To connect from a different network, use a private VPN such as Tailscale or WireGuard. Cross-network access requires internet or another network route; it cannot work with no connection at all.

The current static LAN host is not exposed to the public web. Do not port-forward it. A VPN setup is not automatically configured by this dashboard.

DEVICE CONTROL

Approve or revoke a device

Open DISCORD-SERVER-DASHBOARD/approved_devices.json in Windows Notepad. Add only exact private IP addresses for your own devices. The config is intentionally not served by the web host. Remove an address to revoke it immediately.

Read full private access guide ↗

An empty list allows localhost only. IP filtering is not strong device identity or encryption; use a trusted WPA2/WPA3 network and keep the firewall enabled.

◎
CONSENT REQUIRED

Helping another person

For support on someone else's computer, use a reputable remote-support app where they explicitly approve each session, can see it, and can end it. This dashboard does not secretly control other computers or provide unattended remote access.

Privacy limitation: the local viewer uses HTTP and is read-only. Do not enter passwords, tokens, recovery codes or other secrets. It is not a public website and must never be exposed using router port forwarding. A public hosted site requires HTTPS, account authentication, MFA and server-side authorization, and still needs an internet connection.

SETUP & HELP

Getting started

Quick steps for the new dashboard and private LAN host.

  1. Download or clone the repository on your Windows computer.
  2. Install Python 3.10 or newer from python.org if it is not already installed.
  3. Double-click START_PRIVATE_DASHBOARD.cmd.
  4. Open the local address printed in the console.
  5. For another device, use the displayed private IPv4 address on the same Wi-Fi.
  6. Import a project folder from the Project Library. Source editing happens in the browser on that device.
Compatibility note: folder picking and in-place file saving work best in desktop Chrome or Edge on localhost. iPhone Safari can browse the dashboard and download individual edited files, but it may not support direct folder access or writing back to a selected folder.
