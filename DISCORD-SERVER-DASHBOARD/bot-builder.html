Discord Server & C++ Bot Builder

Set up a Discord server you own, register your own bot application, and start from the included C++17 (D++ / DPP) template. This dashboard guides setup; Discord requires the server owner to approve and complete server creation and bot installation.

Token safety: Never paste your bot token or webhook URL into this website, GitHub, screenshots, or source code. Store secrets in a local environment variable. Give the bot only the permissions it needs.

Create your own Discord server

  1. Open Discord and sign in.
  2. Select the + button in the server list, then choose Create My Own.
  3. Choose a community or friends server, enter a name, and create it.
  4. Open Server Settings → Roles and create a dedicated bot role. Grant only required permissions.
  5. Use the server's invite settings to invite people you choose. Review channel visibility and moderation settings before sharing.

Build your server layout

Choose a name, roles, and channels. The builder creates a downloadable setup blueprint you can follow in Discord.

The Discord API does not let this website create a server on someone's behalf. The server owner must create it in Discord.

Register and invite your own bot

  1. Visit the Discord Developer Portal and select New Application.
  2. Give the application a name. Open the Bot page and add a bot user.
  3. Under Installation / OAuth2, select the bot scope and only the permissions your features need. For this starter, use View Channels, Send Messages, and Use Slash Commands.
  4. Generate an install link and add the bot to the server you own. Do not enable Administrator unless truly necessary.
  5. Copy the bot token once and store it privately as the DISCORD_BOT_TOKEN environment variable on the computer running the bot. Never commit it.
  6. Enable the Guilds intent if requested by your library setup. Slash commands in this sample do not require reading message content.

If a token was ever exposed, reset it immediately in the Developer Portal.

Ticket system

  • One ticket per requester and configured support category.
  • Private access for the requester and authorized support role.
  • Close / reopen controls and a clear audit trail.
  • Rate limit ticket creation and reject duplicate open tickets.
  • Provide a report / abuse path and moderator review.

Webhook notifications

  • Optional notifications only for legitimate events: ticket opened, assigned, or closed.
  • Use a dedicated private channel and a webhook created by the server owner.
  • Store the webhook URL in a server-side secret; never expose it to browser JavaScript.
  • Apply a queue, per-event cooldown, retry cap, and audit log.
  • Never mass-post, flood channels, or repeatedly ping users.

The included C++ starter demonstrates safe slash-command registration and a ticket-intake acknowledgement. Full channel provisioning should be configured with your server's category and support-role IDs before enabling it.

Build the C++17 starter

Download the source and CMake file, install a C++17 compiler and the D++ (DPP) library, then build locally.

Download main.cpp Download CMakeLists.txt

  1. Install CMake, Visual Studio 2022 (Desktop development with C++) or another C++17 toolchain, and DPP.
  2. Set DISCORD_BOT_TOKEN in your local terminal environment. Do not place it in main.cpp.
  3. From the project folder run cmake -S . -B build, then cmake --build build --config Release.
  4. Run the compiled program while logged in to the server where you installed the bot.
  5. Use /ping and /ticket to test the starter commands.
This is a starter bot, not a hosted bot service. It runs only while your computer or server is online. Keep the token private and use a trusted host.
